# Agent rules — canonical

`CLAUDE.md`, `AGENTS.md`, `.cursorrules`, `.windsurfrules` and
`.github/copilot-instructions.md` are copies of the same rules so that whichever
tool a dev uses picks them up automatically.

**This file is the source. If you change the rules, run:**

```bash
npm run sync-agent-rules
```

Covers: Claude Code (`CLAUDE.md`), Codex / OpenAI agents (`AGENTS.md`),
Cursor (`.cursorrules`), Windsurf (`.windsurfrules`), GitHub Copilot
(`.github/copilot-instructions.md`).
